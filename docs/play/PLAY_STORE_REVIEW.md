# Play Store reviewer notes — AI LearnOS

Do **not** commit real production passwords to git. Replace placeholders in Play Console.

## Login

The **release** app authenticates against `API_BASE_URL` (default `https://api.ailearnos.app/v1`). Host that API before review or the reviewer cannot sign in.

Suggested reviewer account (create on the production API; do not reuse git demo passwords in Console if you rotate them):

- Email: `[reviewer@yourdomain.example]`
- Password: `[provide only in Play Console]`

Debug builds may still offer local demo sign-in. That UI is hidden in release.

## Important navigation (student)

1. Sign in  
2. Home — continue learning, AI recommendation  
3. Courses — catalog  
4. Open **UX Design for Beginners** → Learn  
5. AI Tutor tab — ask a question; read the AI accuracy disclaimer  
6. Quiz / assignment from the player  
7. Profile → Subscription (Play Billing; purchases fail closed until products exist)  
8. Settings → Delete account (please do not delete the reviewer account)

## Admin

Admin is a separate role. Provide a reviewer admin only if you want that surface tested.

## Subscriptions

Android digital subscriptions must go through Google Play Billing. Until SKUs are configured, tapping Upgrade shows an error instead of a fake purchase. That is intentional.

## AI

Tutor replies are generated by the backend (mock LLM if `LLM_PROVIDER=mock`). They can be wrong; the UI states that.
