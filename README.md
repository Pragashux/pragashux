# Pragash Santhakumar — UX Designer

Story-driven personal portfolio. Content lives in `src/content/site.ts` so projects, experience, and case-study copy can be updated without rewriting the UI.

## Scripts

```bash
npm install
npm run dev      # http://127.0.0.1:3000
npm run build
npm start
```

## Update a project

Edit the `projects` array in `src/content/site.ts`:

- title, tagline, problem, role, year, client
- cover + `images[]`
- case-study sections (problem, understanding, definition, exploration, system, experience, outcome, learned)
- `tier`: `featured` | `more` | `archive`

Place images in `public/projects/`.
