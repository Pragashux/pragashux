# Pragash — 3D Creator Portfolio

Dark-themed landing page for **Pragash**, presented as Jack, a 3D creator. Built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, and Lucide React.

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- Kanit (Google Fonts, 300–900)

## Scripts

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm run build
npm run preview  # http://127.0.0.1:4173
```

## Sections

1. Hero — navbar, gradient heading, magnetic portrait, contact CTA
2. Marquee — scroll-linked GIF rows
3. About — decorative 3D assets and character-reveal copy
4. Services — five offerings on a white rounded panel
5. Projects — sticky stacking case-study cards
